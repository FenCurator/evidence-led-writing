# Evidence-Led Writing

A Hermes-compatible skill for writing readable reports without overstating what the sources support.

## What it does

- Calibrates language to evidence strength.
- Builds stories around an evidence spine rather than unsupported causation.
- Uses concrete details, meaningful stakes, and scan-friendly structure.
- Adds a counter-editor pass before publication.

## Install in Hermes

Copy `SKILL.md` into a skill directory, or install it from the repository after publishing:

```bash
hermes skills install https://raw.githubusercontent.com/FenCurator/evidence-led-writing/main/SKILL.md
```

The skill is intentionally self-contained. It does not require API keys, private files, a specific search provider, or a particular model.
